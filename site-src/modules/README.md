# Modules

The course runs in eight modules across 16 weeks. Each module page orients
you: what it covers, its lectures, labs, case-study themes, and the skills
you should be able to demonstrate by its end.

| Module | Title | Weeks | Lectures | Cases |
|---|---|---|---|---|
| [M1](m01/index.md) | Network Foundations | 1–2 | L01–L04 | cs-001–010 |
| [M2](m02/index.md) | Network Threats & Attack Mechanics | 3–4 | L05–L08 | cs-011–020 |
| [M3](m03/index.md) | Secure Architecture & Perimeter Controls | 5–6 | L09–L12 | cs-021–040 |
| [M4](m04/index.md) | Cryptographic Foundations & Applied Protocols | 7–8 | L13–L16 | cs-041–053 |
| [M5](m05/index.md) | Wireless & Cloud Network Security | 9–10 | L17–L20 | cs-054–067 |
| [M6](m06/index.md) | Detection, Monitoring & Vulnerability Management | 11–12 | L21–L24 | cs-068–078 |
| [M7](m07/index.md) | Incident Response & SOC Operations | 13–14 | L25–L28 | cs-079–090 |
| [M8](m08/index.md) | Network Forensics & Capstone | 15–16 | L29–L32 | cs-091–100 |

Progression is deliberate: you cannot analyze attack evidence (M2) without
protocol fluency (M1), cannot design segmentation (M3) without knowing what
moves through the network (M1–M2), and cannot run an incident (M7) without
detection infrastructure (M6) or forensics (M8) without evidence discipline
practiced all course long.
