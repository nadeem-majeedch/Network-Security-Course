# Module 8 — Network Forensics & Capstone

**Lectures:** L29–L32 (Weeks 15–16) · **CLOs:** CLO-14, CLO-15 · **Cases:** cs-091–100

*Descriptive orientation. Forensics work uses course-provided evidence
images and captures; chain-of-custody discipline is practiced throughout.*

## What this module covers

The course closes the loop: you reconstruct events from network evidence,
report findings defensibly, then integrate everything into the capstone —
a full security assessment of a simulated organization, an IR simulation,
and a defended design.

## Case studies (expert tier — the Meridian capstone arc)

cs-091–100 form one coherent arc on the simulated Meridian organization:
breach-readiness assessment → remediation roadmap → zero-trust migration
design → board risk report → IR exercise design → threat-hunt hypotheses →
forensic multi-source correlation → capstone design defense prep → IR
simulation under time pressure → full-scope incident walkthrough.
See the [case studies guide](../../cases/index.md).

## Skills checkpoints

- Preserve and document evidence so a timeline can survive scrutiny.
- Correlate flow, log, and capture sources into one defensible event narrative.
- Scope an intrusion across a segmented enterprise without over- or under-claiming.
- Defend a security design decision against structured technical challenge.
