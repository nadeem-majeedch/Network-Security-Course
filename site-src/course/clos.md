# Course Learning Outcomes (CLOs)

By the end of this course, students will be able to:

| CLO | Outcome |
|---|---|
| **CLO-1** | Analyze network protocols (Ethernet, ARP, IP, ICMP, TCP, UDP, DNS, DHCP) and identify their security-relevant behaviors and failure modes |
| **CLO-2** | Identify and classify network threats and attack mechanics (Layer-2 attacks, sniffing/MITM, denial of service) and map them to defense opportunities |
| **CLO-3** | Design network segmentation and defense-in-depth architectures grounded in sensitivity, behavior, and operational realism |
| **CLO-4** | Engineer firewall policy and ACL rulebases with first-match discipline, audit hygiene, and change control |
| **CLO-5** | Apply cryptographic foundations (symmetric, asymmetric, hashing, MACs, signatures) to select appropriate protections for data in motion and at rest |
| **CLO-6** | Analyze TLS and PKI deployments, validate certificate chains, and design certificate lifecycle automation |
| **CLO-7** | Design and evaluate VPN architectures (IPsec, modern remote access) with honest trust-boundary reasoning |
| **CLO-8** | Secure enterprise wireless networks and defend against rogue access points and identity attacks |
| **CLO-9** | Operate network detection systems (IDS/IPS, Zeek, flow analytics) including signature tuning with regression safety |
| **CLO-10** | Run a vulnerability management lifecycle with environmental prioritization, SLAs, and verifiable metrics |
| **CLO-11** | Execute the incident response lifecycle with reversible-first containment, eradication verification, and recovery go/no-go discipline |
| **CLO-12** | Corroborate security evidence across multiple telemetry sources and communicate findings with confidence labels |
| **CLO-13** | Design and assess cloud network security (VPCs, security groups, egress control, hybrid connectivity) |
| **CLO-14** | Conduct network forensics with proper evidence handling and produce defensible multi-source timelines and reports |
| **CLO-15** | Synthesize the full curriculum into a capstone: secure architecture design, build evidence, incident exercise, and defense-grade communication |

## Bloom's level distribution

The assessment layer deliberately spans all six Bloom levels, with the
center of gravity at **Apply–Analyze** for quizzes and
**Evaluate–Create** for assignments, the capstone, and the oral defense.
