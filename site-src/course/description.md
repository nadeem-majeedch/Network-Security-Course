# Course Description

## Course identity

| Attribute | Value |
|---|---|
| Course | Network Security |
| Audience | BS Computer Science / BS Data Science — 7th semester |
| Duration | 16 weeks · 32 lectures · 2 hours each (64 contact hours) |
| Format | Lectures + weekly labs + case studies + capstone project |
| Lab environment | Isolated, instructor-authorized virtual lab range only |

## Overview

Network Security is a senior-level, practice-intensive course that
teaches how networked systems are attacked and, more importantly, how
they are defended. The course grounds every security control in the
protocol it protects: students first master the behavior of Ethernet,
ARP, IP, ICMP, TCP, UDP, DNS, and DHCP — including IPv4/IPv6 addressing
and routing — and then study how reconnaissance, spoofing, sniffing,
denial-of-service, and man-in-the-middle techniques exploit those exact
mechanics. With that foundation, the course turns to the defender's
craft: firewalls and segmentation, cryptography and secure channels
(TLS, IPsec, modern VPNs), wireless and cloud networking, detection and
monitoring, vulnerability management, incident response, network
forensics, and finally a capstone that designs, builds, exercises, and
defends a complete secure architecture.

## What students will be able to do

Graduates of this course can read network evidence fluently; design
segmented, zero-trust-informed architectures; deploy and audit secure
channels; operate detection pipelines with honest metrics; run an
incident response lifecycle with reversible-first containment; produce
defensible forensic timelines; and present security posture to a
non-technical board. The complete outcome list is on the
[CLOs page](clos.md).

## Ethics and safety framing

All attack content is taught **conceptually and defensively**: every
scenario in lectures, labs, and the 100-case collection is simulated
and labeled as such; all practical work happens on an isolated,
instructor-authorized range; and no offensive tooling, destructive
payloads, or real-incident indicators appear in course materials.
Students take an authorization-and-ethics contract in week 1 (see
[Lecture 1](../lectures/lecture-01-security-mindset-threat-landscape.md)).

## Prerequisites

- Computer Networks (layer models, addressing, TCP/IP basics)
- Operating systems fundamentals; basic Linux familiarity
- Programming experience in any language (Python helpful for the data
  science track)
