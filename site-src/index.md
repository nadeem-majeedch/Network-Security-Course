# Network Security Course

**A 16-week, 32-lecture university course on defending networked
systems — for BS Computer Science and BS Data Science students.**

Every security control in this course is grounded in the protocol it
protects. You will read packets before you fight fires, design
segmentation before you buy boxes, and rehearse incident response
before you need it.

## What makes this course different

1. **Protocol-grounded defense.** Attacks are taught as *exploitations
   of protocol mechanics* — ARP trusts whoever shouts first; TLS chains
   break on missing intermediates. Defenses follow from the mechanics.
2. **Judgment, not just tooling.** Containment sequencing,
   reversibility labeling, and honest reporting are graded skills — the
   same discipline professionals defend in post-incident reviews.
3. **Honest scope.** All scenarios are simulated and clearly labeled;
   the course teaches defense; instructor answer keys are never
   published on this site.
