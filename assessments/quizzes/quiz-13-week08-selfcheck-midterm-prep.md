# Self-Check Quiz 13 — Week 8 (Midterm Preparation, L01–L16)

> Not graded — a midterm warm-up spanning weeks 1–7. Answers in the course
> answer key.

1. **(MCQ)** Which sequence correctly orders attack → detection → design
   concepts from weeks 1–7?
   A. ARP spoofing → DAI → segmentation · B. Segmentation → ARP spoofing →
   DAI · C. DAI → segmentation → ARP spoofing · D. DAI → ARP spoofing →
   segmentation

2. **(MCQ)** A capture shows TCP SYN with no matching SYN-ACK and many
   distinct sources. The best first hypothesis:
   A. Reflection attack · B. Distributed SYN flood · C. DNS poisoning ·
   D. ARP scanning

3. **(MCQ)** Which control pair maps to the *same* trust boundary?
   A. DMZ filtering + egress allow-list · B. VPN MFA + badge readers ·
   C. NACL + application logging · D. WPA3 + disk encryption

4. **(MCQ)** The strongest indicator that a TLS deployment is *maintained*
   (not just present):
   A. TLS 1.3 enabled · B. Automation for issuance/rotation with monitored
   expiry · C. RSA-4096 key · D. HSTS preload

5. **(MCQ)** Hashing, MAC, and digital signature differ by:
   A. Key usage — none / symmetric / asymmetric · B. Speed only ·
   C. Output length · D. Algorithm age

6. **(Short)** Name the single most common misconfiguration class in the
   week 1–7 material (one sentence), and the verification habit that
   catches it. *(2 marks)*

7. **(Diagram)** A network diagram shows: internet → edge FW → DMZ (web) →
   inner FW → internal; a VPN concentrator hangs off the edge FW. Mark the
   two points where MFA applies, and the flow most often forgotten in this
   design. *(2 marks)*

8. **(Short)** In ≤3 sentences, connect a *protocol* fact (from weeks 1–2)
   to a *defense* decision (from weeks 5–6). *(2 marks)*

**Total: 10 marks**
