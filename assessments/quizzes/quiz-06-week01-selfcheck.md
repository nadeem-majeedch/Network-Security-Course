# Self-Check Quiz 6 — Week 1 (CIA, Risk Vocabulary, Frames)

> Not graded — use after L01/L02. Answers in the course answer key.
> If you miss Q4, Q5, or Q7, re-run Lab-01 §4 before continuing.

1. **(MCQ)** Which order correctly lists encapsulation from data to wire?
   A. Segment → packet → frame · B. Frame → packet → segment ·
   C. Packet → segment → frame · D. Datagram → frame → segment

2. **(MCQ)** A "vulnerability" differs from a "threat" because it is:
   A. The actor · B. The weakness · C. The impact · D. The likelihood

3. **(MCQ)** Risk, quantitatively, is best expressed as:
   A. Threat × vulnerability × impact · B. Impact − likelihood ·
   C. Threat + impact · D. Vulnerability ÷ threat

4. **(MCQ)** The frame field that identifies the intended receiving
   interface on the local link is the:
   A. Source IP · B. Destination MAC · C. TTL · D. DNS name

5. **(MCQ)** Which device makes forwarding decisions using IP destination
   and a routing table?
   A. Hub · B. Switch · C. Router · D. Repeater

6. **(Short)** Give one security-relevant difference between a broadcast
   domain and a collision domain. *(2 marks)*

7. **(Short)** A laptop holding unreleased financial results is stolen.
   Classify the primary CIA impact and justify in one sentence. *(2 marks)*

8. **(Diagram)** A diagram shows two PCs connected to the same switch, the
   switch uplinked to a router, and the router to the internet. Mark which
   link-layer domain the two PCs share, and what the router terminates.
   *(2 marks)*

**Total: 10 marks** *(MCQ 1 each = 5; short/diagram = 5)*
