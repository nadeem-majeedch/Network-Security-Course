# Student Lecture Materials — NS-401 Network Security

One page per lecture (32 total). Each page contains: learning objectives, key
definitions, detailed explanations, a network diagram, protocol examples,
configuration concepts, security implications, an organizational scenario,
common misconceptions, classroom activities, problem-solving questions, an exit
ticket, references, and CLO mapping.

**Instructor materials (speaker notes, answer keys, manual) live under `teaching/`
and are excluded from student distribution.** Corresponding instructor teaching
plans: `modules/module-*/lectures/`.
