# Answer Key — Self-Check Quiz 16 (Capstone Defense Preparation)

> This self-check rehearses the defense guide's standards
> (`assessments/capstone/defense-guide.md`); answers there carry the
> authority — this key restates them.

1. **B** — named deferral + accepted risk + pairing control + agreement =
   governance; the others are evasions.
2. **B** — name the drift mode (exception accumulation, stale rules, blind
   spots) *plus* reviewer cadence/owner; "nothing fails silently" reads
   as inexperience.
3. **B** — claims trace to measured evidence (pilot, probe, replay);
   A/C/D dodge the evidentiary question.
4. **B** — evidence basis + reversibility class per decision (the
   course's through-line); mood/brand/deadline are not decision quality.
5. **B** — incident/response + honest limits + specific ask (the cs-094
   structure).
6. **(2)** Full credit: a *real* named gap (not performative humility) +
   a concrete closure path (pilot, test, review, telemetry). Evasions
   ("we're confident in everything") cap at 1.
7. **(2)** Full credit: a specific single-point-of-failure (often the
   IdP/policy engine, per cs-098) + a designed fallback (break-glass,
   degraded mode, offline procedure). No fallback named = 1/2 max.
8. **(2)** Full credit: one sentence, outcome-phrased, jargon-free
   ("We can now detect in days what previously took weeks, and contain
   it in hours without specialist help").
